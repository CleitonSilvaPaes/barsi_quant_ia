# Scripts de Migração e Carga — Agnósticos

Scripts portáteis para população inicial e migração de dados:

- `migrate_budget_seed.py`: Semeia as despesas orçamentárias padrão no SQLite de forma 100% idempotente.
- `migrate_xlsx_to_sheets.py`: Converte e carrega a planilha local Excel para o Google Sheets.
